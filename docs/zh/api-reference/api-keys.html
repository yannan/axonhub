API Key 管理

基于当前 GraphQL Schema，整理 API Key 的创建（createAPIKey）、列表查询（apiKeys）与更新（updateAPIKey）操作。 适用于后台 GraphQL 接口：POST /admin/graphql。

Content-Type: application/json Authorization: Bearer <JWT> Schema: axonhub/internal/server/gql

通用请求格式

{
"query": "query GetApiKeys($first: Int) { apiKeys(first: $first) { totalCount } }",
"variables": { "first": 20 },
"operationName": "GetApiKeys"
}

GraphQL Endpoint 为 /admin/graphql，请求体采用 JSON，鉴权头需携带 JWT。

API Key 类型枚举：user / service_account。 状态枚举：enabled / disabled / archived。

id

user { id email }

profiles {
activeProfile
profiles {
name

modelMappings { from to }
}
}
}
cursor
}
pageInfo { hasNextPage hasPreviousPage startCursor endCursor }

}
}
{
"first": 20,
"orderBy": { "field": "CREATED_AT", "direction": "DESC" },
"where": { "status": "enabled", "projectID": "Project:1" }
}
提示：APIKey 列表一般无需返回 key 字段，创建时建议单独查询或依赖 createAPIKey 的返回值。

创建 API Key - createAPIKey

Mutation 签名：createAPIKey(input: CreateAPIKeyInput!): APIKey!

mutation CreateAPIKey($input: CreateAPIKeyInput!) {
createAPIKey(input: $input) {
id
key
name
type
status
scopes
ipWhitelist
contentSafetyInterceptEnabled
project { id name }
createdAt
updatedAt
}
}
{
"input": {
"name": "Ops Key",
"type": "service_account",
"scopes": ["read_channels", "write_requests"],
"ipWhitelist": "10.0.0.1\\n10.0.0.2",
"contentSafetyInterceptEnabled": true,
"projectID": "Project:1"
}
}

输入字段（CreateAPIKeyInput）

字段 类型 必填 说明
name String 是 API Key 名称
type APIKeyType 否 类型：user / service_account
scopes [String!] 否 API Key 权限范围；user 类型固定为 read_channels、write_requests
ipWhitelist String 否 允许访问的 IP 白名单，按行分隔；为空表示允许全部
contentSafetyInterceptEnabled Boolean 否 是否启用该 API Key 的内容安全拦截（默认 true）
projectID ID 是 归属项目 ID

更新 API Key - updateAPIKey

Mutation 签名：updateAPIKey(id: ID!, input: UpdateAPIKeyInput!): APIKey!

mutation UpdateAPIKey($id: ID!, $input: UpdateAPIKeyInput!) {
updateAPIKey(id: $id, input: $input) {
id
name
type
status
scopes
ipWhitelist
contentSafetyInterceptEnabled
updatedAt
}
}
{
"id": "APIKey:32",
"input": {
"name": "Ops Key v2",
"appendScopes": ["read_models"],
"clearIPWhitelist": true
}
}

输入字段（UpdateAPIKeyInput）

字段 类型 必填 说明
name String 否 API Key 名称
scopes [String!] 否 替换全部权限范围
appendScopes [String!] 否 追加权限范围
clearScopes Boolean 否 清空权限范围
ipWhitelist String 否 设置新的 IP 白名单
clearIPWhitelist Boolean 否 清空 IP 白名单
contentSafetyInterceptEnabled Boolean 否 是否启用该 API Key 的内容安全拦截
UpdateAPIKey 只更新可变字段；如需修改状态或 Profile，请使用对应的 mutation。

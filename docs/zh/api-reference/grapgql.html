项目创建与编辑

基于当前 GraphQL Schema，整理项目创建（createProject）与项目编辑（updateProject）两个 Mutation 的静态文档。 适用于后台 GraphQL 接口：POST /admin/graphql。

Content-Type: application/json Authorization: Bearer <JWT> Schema: axonhub/internal/server/gql

通用请求格式

{
"query": "mutation MyMutation($input: CreateProjectInput!) { createProject(input: $input) { id name status } }",
"variables": { "input": { "name": "Demo Project" } },
"operationName": "MyMutation"
}

GraphQL Endpoint 为 /admin/graphql，需携带 JWT 鉴权头。Project 的状态枚举值来自 Schema： active archived

Project 类型字段 description 为非空字符串。创建时若不填写，后端通常会落为空字符串（依 Ent 默认值而定）。

创建项目 - createProject

Mutation 签名：createProject(input: CreateProjectInput!): Project!

mutation CreateProject($input: CreateProjectInput!) {
createProject(input: $input) {
id
name
description
status
group
createdAt
updatedAt
}
}
{
"input": {
"name": "AxonHub Docs",
"description": "用于演示的项目",
"status": "active",
"group": "default",
"userIDs": ["User:1", "User:2"]
}
}

输入字段（CreateProjectInput）

字段 类型 必填 说明
name String 是 项目名称
description String 否 项目描述
status ProjectStatus 否 项目状态：active / archived
group String 否 计费分组：default / vip / svip
userIDs [ID!] 否 创建时同时加入的用户 ID 列表

编辑项目 - updateProject

Mutation 签名：updateProject(id: ID!, input: UpdateProjectInput!): Project!

mutation UpdateProject($id: ID!, $input: UpdateProjectInput!) {
updateProject(id: $id, input: $input) {
id
name
description
status
group
updatedAt
}
}
{
"id": "Project:42",
"input": {
"name": "AxonHub Docs v2",
"description": "更新项目描述",
"status": "active",
"addUserIDs": ["User:9"],
"removeUserIDs": ["User:7"],
"clearUsers": false
}
}

输入字段（UpdateProjectInput）

字段 类型 必填 说明
name String 否 项目名称
description String 否 项目描述
status ProjectStatus 否 项目状态：active / archived
group String 否 计费分组：default / vip / svip
addUserIDs [ID!] 否 新增项目成员
removeUserIDs [ID!] 否 移除项目成员
clearUsers Boolean 否 是否清空全部成员

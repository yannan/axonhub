GraphQL Operations 快照

该页面用于展示 AxonHub 的 GetRequests 与 GetTraces 操作定义，便于快速复制并在 GraphQL 控制台或前端调用中使用。

Query Operation

GetRequests

分页获取请求列表，并带回成本字段。

Variables
  • first, after, last, before
  • orderBy, where
Query
query GetRequests(
  $first: Int
  $after: Cursor
  $last: Int
  $before: Cursor
  $orderBy: RequestOrder
  $where: RequestWhereInput
) {
  requests(first: $first, after: $after, last: $last, before: $before, orderBy: $orderBy, where: $where) {
    edges {
      node {
        id
        createdAt
        updatedAt
        source
        modelID
        stream
        status
        cost
        metricsLatencyMs
        metricsFirstTokenLatencyMs
        trace {
          id
          traceID
          cost
        }
        usageLogs(first: 1) {
          edges {
            node {
              id
              promptTokens
              completionTokens
              totalTokens
              promptCachedTokens
              promptWriteCachedTokens
            }
          }
        }
      }
      cursor
    }
    pageInfo {
      hasNextPage
      hasPreviousPage
      startCursor
      endCursor
    }
    totalCount
  }
}
提示：如果后端已支持 Request.cost，可以直接使用根字段；如需回退，也可读取 trace.cost。
Query Operation

GetTraces

分页获取 Trace 列表，并带回 cost 与请求统计。

Variables
  • first, after
  • orderBy, where
Query
query GetTraces(
  $first: Int
  $after: Cursor
  $orderBy: TraceOrder
  $where: TraceWhereInput
) {
  traces(first: $first, after: $after, orderBy: $orderBy, where: $where) {
    edges {
      node {
        id
        traceID
        cost
        firstUserQuery
        createdAt
        updatedAt
        thread {
          id
          threadID
        }
        requests(where: { status: completed }) {
          totalCount
        }
        blockedRequests: requests(where: { status: blocked }) {
          totalCount
        }
      }
      cursor
    }
    pageInfo {
      hasNextPage
      hasPreviousPage
      startCursor
      endCursor
    }
    totalCount
  }
}
